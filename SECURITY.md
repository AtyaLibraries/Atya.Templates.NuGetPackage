# Security

## Supported versions

| Version | Supported |
| --- | --- |
| Latest released major/minor | Yes |
| Earlier major/minor versions | No, unless explicitly listed in a security advisory |
| Prerelease builds | No |

## Private disclosure

Do not open a public issue for a suspected vulnerability. Use the repository's
[private GitHub Security Advisory](https://github.com/__GITHUB_OWNER__/Atya.Templates.NuGetPackage/security/advisories/new)
to share impact, affected versions, reproduction steps, and any proposed fix.

If encrypted email is required, use the public keys published at
[__GITHUB_OWNER__.gpg](https://github.com/__GITHUB_OWNER__.gpg) and include a
link to the private advisory.

## Response targets

The maintainers will acknowledge a complete report within 5 business days.
Validation, remediation, and release timing depend on severity and complexity,
but reporters will receive status updates through the private advisory.

## CVE handling

For confirmed vulnerabilities, maintainers will coordinate a fix privately,
request a CVE through GitHub when appropriate, publish patched packages, and
release a GitHub Security Advisory with affected and fixed version ranges.
Public disclosure occurs after a supported fix is available or on a mutually
agreed disclosure date.
